# Website fonts

The website self-hosts five WOFF2 faces. Inter 400 is body text; Inter 500/600 provides interface and emphasis roles. Manrope 700/800 provides display and heading roles. The stylesheet explicitly maps these faces and uses `font-display: swap`, so text remains readable while a font loads. No third-party font service is requested.

Both families are distributed under the SIL Open Font License 1.1. Preserve their original copyright and full notices: [Inter](inter/LICENSE.txt) and [Manrope](manrope/LICENSE.txt). Font projects: [Inter](https://github.com/rsms/inter) and [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope). Fontsource supplied the web-font distribution used by the website.

Unused historical weights were retired; retaining a font file does not make it part of the current typography system. Changing the faces requires reviewing actual stylesheet requests, fallbacks, appearance and applicable notices.
