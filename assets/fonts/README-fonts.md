# Fonts

Two typefaces, served from this site so that no visitor's browser contacts a font service: **Inter** for text, in regular, medium, and semibold, and **Manrope** for headings, in bold and extra bold.

Both are published under the SIL Open Font License 1.1, and their full notices are kept with the files: [Inter](inter/LICENSE.txt), © The Inter Project Authors, and [Manrope](manrope/LICENSE.txt), © The Manrope Project Authors. Projects: [Inter](https://github.com/rsms/inter) and [Manrope](https://github.com/sharanda/manrope); web-font files from Fontsource. The licence covers the fonts only, not the site's text or artwork.
