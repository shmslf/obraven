# Website images

`stan-herasymenko-portrait.webp` is the current portrait used on the About page. Its web format and crop serve the website layout; replacing it requires checking appearance, alt text, dimensions and existing page references together.

The unused larger JPEG is no longer part of the current website. Website resources are deployment copies; reusable portrait originals and derivatives are maintained separately. Publication here does not grant a general licence to reuse photographs.
